# Greeting Card Project 

This project is part of the **freeCodeCamp Responsive Web Design workshop**.  
It demonstrates how to build an interactive greeting card using **HTML** and **CSS**.

## Features 
- Styled card layout with hover effects
- Smooth transitions for background color and scaling
- Interactive links to send or share the card
- Sections revealed dynamically using `:target`
- Fun emoji decorations with pseudo-elements
- Flexbox layout for link spacing
- Styled buttons with hover and active states

## Technologies Used 
- HTML5
- CSS3 (Flexbox, Transitions, Pseudo-elements)

## How It Works 
- The card has two main actions: **Send Card** and **Share on Social Media**.
- Clicking a link reveals the corresponding section (`#send` or `#share`) using CSS `:target`.
- Hovering over the card enlarges it slightly and changes its background color.
- Links are styled as buttons with hover and active states.


## Demo 
Open `index.html` in your browser to see the interactive greeting card in action.
